# SHAHED.exe — FPV Mayhem

Игровой Fabric-мод для **Minecraft Java Edition 26.2** от вымышленной компании **ТОВ «КРИВІ РУКИ AEROSPACE»**.

> «Злетіти легко. Посадити — не обіцяємо».

**Этап 2, доработка 0.2.1:** аркадный самолётный полёт с полноэкранной FPV-камерой. Игрок размещает свой дрон, привязывает пульт к его UUID, надевает FPV-очки и подключается. Тело остаётся в мире; сервер рассчитывает движение и проверяет право управления. Это игровой мод Minecraft.

Исходное ТЗ и дальнейшие этапы — [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md), фактические результаты проверок и ручные сценарии — [docs/TESTING.md](docs/TESTING.md), состав проекта — [docs/FILES.md](docs/FILES.md).

## Что реализовано

- Тяга с плавным набором и сбросом, линейная и угловая инерция, аэродинамическое сопротивление, гравитация и подъёмная сила от обдува крыла. Отпускание клавиш и выход из FPV сохраняют импульс: дрон планирует и теряет высоту при недостатке тяги.
- Тангаж направляет тягу; крен наклоняет подъёмную силу и постепенно меняет траекторию. Тормоз увеличивает сопротивление, без мгновенного обнуления скорости в воздухе.
- Полноэкранная FPV-камера с захватом мыши, наклонами и настраиваемой плавностью. Рука, пульт и обычный HUD не закрывают изображение.
- UUID-привязка пульта к собственному дрону, проверка владельца и экипировки на сервере, независимые сеансы игроков.
- HUD: скорость, абсолютная высота Y, время текущего сеанса и идентификатор дрона.
- Подключение без ограничения расстояния и потери радиосигнала. Загрузка и отправка чанков вокруг управляемого дрона следуют за камерой; тело игрока остаётся на месте.
- Увеличенная модель дрона длиной около 3,7 блока, консервативный hitbox 3,9 × 1,3 блока, объёмные модели пульта и очков. Положение очков скорректировано к области лица.
- Завершение FPV при явном выходе, смерти, повреждении/перемещении тела, снятии оборудования, удалении дрона, смене измерения и отключении от сервера.

Автоматическая сборка проверяет серверную логику и ресурсы; оценка управляемости, посадки очков и вида 3D-моделей требует графического клиента. **Выделенный сервер с двумя настоящими игроками ещё не проверен.** Текущий протокол отделён от результатов версии 0.2.0 в [docs/TESTING.md](docs/TESTING.md). Реплеи, гонки, звуки, взрывы и новые визуальные эффекты в эту доработку не входят.

## Версии и сборка

| Компонент | Версия |
| --- | --- |
| Minecraft Java Edition | `26.2` |
| Java JDK | `25` |
| Fabric Loader | `0.19.5` |
| Fabric API | `0.161.0+26.2` |
| Gradle Wrapper | `9.7.1` |
| Fabric Loom | `1.18.4` |

Версии закреплены в `gradle.properties`, `build.gradle` и `gradle/wrapper/gradle-wrapper.properties`. Используйте JDK 25 и Wrapper из существующего checkout:

```bash
java -version
./gradlew --version
./gradlew build
```

`build` запускает серверные GameTest. Бинарный мод — `build/libs/shahed-fpv-mayhem-0.2.1.jar`, исходники — `build/libs/shahed-fpv-mayhem-0.2.1-sources.jar`, свежий отчёт — `build/gametest-results.xml`. `-sources.jar` не устанавливают в `mods`.

```bash
./gradlew runClient
./gradlew runServer
```

Клиенту нужна графическая среда. Для обычного сервера прочитайте и самостоятельно примите Minecraft EULA в созданном `eula.txt`. Проверку TLS, подписей и контрольных сумм при установке сохраняют.

## Установка

1. Установите Java 25 и профиль Fabric для Minecraft 26.2 / Loader 0.19.5 через [официальный установщик](https://fabricmc.net/use/installer/).
2. Поместите Fabric API `0.161.0+26.2` и `shahed-fpv-mayhem-0.2.1.jar` в `mods` этого профиля. Удалите старый JAR мода, чтобы не загружать две версии одновременно.
3. Для первого полёта создайте творческий мир с разрешёнными командами и просторной открытой площадкой.

На выделенном сервере нужны те же версии Minecraft, Loader, Fabric API и мода. Клиент и сервер обновляют до 0.2.1 вместе: сетевые пакеты этой версии отличаются от 0.2.0. После установки официального Fabric Server используйте его launcher, например:

```bash
java -Xms1G -Xmx2G -jar fabric-server-launch.jar nogui
```

Память выбирают под мир и остальные моды. Сервер загружает общую игровую логику и сетевые пакеты; FPV-камера работает на клиенте.

## Первый полёт

1. Выполните `/shahed kit`. Разместите дрон предметом на свободной площадке либо выполните `/shahed spawn`. Эти способы назначают владельцем создавшего дрон игрока.
2. Нажмите ПКМ пультом по **своему** дрону. Пульт сохраняет UUID дрона и владельца. Для другого своего дрона повторите привязку.
3. Наденьте FPV-очки в слот головы и возьмите привязанный пульт в одну из рук.
4. Нажмите ПКМ в воздух: после подтверждения сервера камера переключится на дрон.
5. Наберите скорость с `W`, используйте `Space` для помощи в наборе высоты. Для взлёта оставьте место для разгона: подъёмная сила зависит от скорости, дрон не взлетает вертикально с места.
6. Нажмите **R** для выхода. Самолёт продолжит движение по инерции и снижение; перед выходом посадите его, если хотите оставить на месте.

Отказ при подключении вызывают отсутствие привязки/очков/удерживаемого пульта, чужой владелец и недоступный дрон. Ограничения дальности нет. Дрон должен существовать и быть загружен в том же измерении. Ванильный `/summon shahed:drone` создаёт сущность без владельца и не заменяет штатное размещение.

| Клавиша по умолчанию | Действие в FPV |
| --- | --- |
| `W` | Увеличить тягу двигателя |
| `S` | Убрать тягу и включить воздушное торможение |
| `A` / `D` | Накренить аппарат влево / вправо |
| `Space` | Помощь в наборе высоты: поднять нос и дать тягу |
| `Left Ctrl` | Опустить нос для снижения |
| `Left Shift` | Усиленное торможение |
| Мышь | Поворот и тангаж |
| `←` / `→` | Поворот с клавиатуры |
| `↑` / `↓` | Тангаж с клавиатуры |
| `R` | Завершить FPV-сеанс |
| `K` | Параметры FPV |

Максимальная скорость — 16 м/с, тангаж ограничен ±65°. При отпускании управления двигатель плавно сбрасывает тягу, а линейная и угловая скорость сохраняются и постепенно гасятся сопротивлением. Наклон носа не разворачивает накопленный импульс мгновенно. `S` тормозит самолёт, заднего хода нет. При недостатке обдува/тяги аппарат снижает высоту; выход из FPV также не фиксирует его в воздухе. Нулевая скорость допустима после столкновения или касания земли. Обычный урон может уничтожить дрон.

Клавиши меняются в **Настройки → Управление → Назначение клавиш**, раздел SHAHED.exe FPV. Параметры `K`: множитель чувствительности мыши 0,10–3,00 (по умолчанию 1,00), сглаживание ориентации 0–0,50 с (0,12 с), инверсия тангажа (выключена). Учитываются стандартная чувствительность Minecraft и её настройки инверсии. Параметры сохраняются локально в `config/shahed-fpv.json`. Меню убирает управляющий ввод, не замораживая самолёт; сервер продолжает работать. Во время FPV обычное использование предметов и смена панели быстрого доступа заблокированы. Выход доступен через `R` или кнопку меню `K`.

## Подключение, тело игрока и мультиплеер

Радиосвязь не моделируется: нет падения сигнала, расстояния отключения, экрана «нет сигнала» и автоматического выхода по тайм-ауту телеметрии. Сервер направляет отслеживание сущностей и отправку местности к дрону, сохраняя обычное положение тела. Временные серверные билеты чанков следуют за дроном и освобождаются при выходе; они не сохраняют принудительную загрузку после перезапуска. При подгрузке местности движение может ожидать готовности чанка без сброса импульса.

Тело остаётся уязвимым. Сервер останавливает его обычное движение; получение урона, смерть, перенос тела и смена измерения завершают сеанс. Снятие очков или удаление привязанного пульта из обеих рук также завершает FPV.

Сервер проверяет владельца, UUID, оборудование и текущий сеанс. Клиент отправляет команды ввода, а не готовую позицию. У каждого игрока свой сеанс; один дрон доступен одному пилоту. Если свежий ввод не поступает 10 тиков (0,5 с при 20 TPS), сервер заменяет старые команды нейтральными. Сам сеанс остаётся подключённым, импульс и гравитация продолжают действовать, свежие пакеты восстанавливают управление. Выход, отключение от сервера и удаление дрона возвращают камеру к игроку.

Высота HUD — **координата Y мира**, не высота над ближайшей поверхностью. Время — длительность текущего подключения; после нового подключения отсчёт начинается заново. Батарея и ресурс двигателя не моделируются.

## Оборудование и команды

| Идентификатор | Назначение |
| --- | --- |
| `shahed:drone` | Предмет творческого размещения собственного дрона; также ID сущности |
| `shahed:controller` | Объёмный пульт с UUID-привязкой дрона и владельца |
| `shahed:fpv_goggles` | Объёмные очки для слота головы, обязательны для подключения |

```mcfunction
/gamemode creative
/shahed kit
/shahed spawn
```

`/shahed spawn` размещает дрон перед игроком. Крупный hitbox должен полностью помещаться на свободном месте, в загруженных чанках и границах мира. `/shahed` и предмет размещения требуют творческого режима; подключение и полёт дополнительно проверяют оборудование и владельца.

Доступны `/give @s shahed:drone`, `/give @s shahed:controller`, `/give @s shahed:fpv_goggles` и `/summon shahed:drone ~ ~1 ~` с обычными правами Minecraft. Удалить тестовую сущность можно через `/kill @e[type=shahed:drone,distance=..8]`; активный сеанс должен завершиться.
