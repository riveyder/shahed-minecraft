# SHAHED.exe — FPV Mayhem

Игровой Fabric-мод для **Minecraft Java Edition 26.2** от вымышленной компании **ТОВ «КРИВІ РУКИ AEROSPACE»**.

> «Злетіти легко. Посадити — не обіцяємо».

**Этап 2: аркадный полёт с полноэкранной FPV-камерой.** Игрок размещает свой дрон, привязывает пульт к его UUID, надевает FPV-очки и подключается. Тело остаётся в мире; сервер рассчитывает движение дрона и проверяет право управления. Мод предназначен для Minecraft и не подключается к реальным беспилотным системам.

Исходное ТЗ и дальнейшие этапы находятся в [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md). Автоматические результаты и подробный ручной сценарий — в [docs/TESTING.md](docs/TESTING.md), состав проекта — в [docs/FILES.md](docs/FILES.md).

## Что реализовано

- Аркадный полёт: разгон, инерция, торможение, горизонтальное движение, подъём и снижение, поворот и тангаж, наклон модели и камеры.
- Полноэкранный вид от дрона с захватом мыши; пульт, рука игрока и обычный HUD не закрывают FPV-изображение.
- Привязка пульта к UUID своего дрона; проверка владельца и экипировки на сервере.
- Настраиваемые клавиши, чувствительность мыши, плавность камеры и отдельный выход.
- HUD: скорость, абсолютная высота Y, условный уровень сигнала, время текущего сеанса и UUID дрона.
- Серверное управление, синхронизация положения и отдельные сеансы для игроков.
- Завершение сеанса при выходе, смерти, повреждении тела, потере оборудования, удалении дрона, смене измерения, потере связи и отключении.

Сборка и все 24 серверных GameTest прошли. В клиенте с виртуальным дисплеем проверены подключение, полёт, крен, HUD и возврат камеры. Расширенная проверка на обычном клиенте и несколько настоящих клиентов остаются ручными сценариями — подробный протокол в [docs/TESTING.md](docs/TESTING.md). Реплеи, гонки, Advanced, расширенные эффекты, физическая симуляция радиосигнала, анимация винта и звук не входят в этот этап.

Значения закреплены в `gradle.properties`, `build.gradle` и `gradle/wrapper/gradle-wrapper.properties`. Нужны JDK 25 и доступ к официальным серверам зависимостей. Используйте Wrapper из репозитория:

```bash
java -version
./gradlew --version
./gradlew build
```

`build` запускает серверные GameTest. Бинарный мод — `build/libs/shahed-fpv-mayhem-0.2.0.jar`, исходники — `build/libs/shahed-fpv-mayhem-0.2.0-sources.jar`, отчёт — `build/gametest-results.xml`. `-sources.jar` не устанавливают в `mods`. Текущий результат проверки этапа 2 записывается в [docs/TESTING.md](docs/TESTING.md); успешная компиляция не подтверждает внешний вид камеры.

```bash
./gradlew runClient
./gradlew runServer
```

Клиенту нужна графическая среда. Для обычного сервера прочитайте и самостоятельно примите Minecraft EULA в созданном `eula.txt`. При повторении установки сохраняйте проверку TLS, подписей и контрольных сумм.

## Установка

1. Установите Java 25 и профиль Fabric для Minecraft 26.2 / Loader 0.19.5 через [официальный установщик](https://fabricmc.net/use/installer/).
2. Поместите Fabric API `0.161.0+26.2` и бинарный JAR мода в `mods` этого профиля.
3. Для проверки создайте творческий мир с разрешёнными командами.

На выделенном сервере нужны те же версии Minecraft, Loader, Fabric API и мода. После установки официального Fabric Server используйте его launcher, например:

```bash
java -Xms1G -Xmx2G -jar fabric-server-launch.jar nogui
```

Выберите память под мир и остальные моды. Клиентская камера работает на клиенте; сервер загружает общую игровую логику и сетевые пакеты.

## Первый полёт

1. В творческом мире выполните `/shahed kit` и разместите дрон предметом на свободной площадке либо выполните `/shahed spawn`. Эти способы назначают владельцем создавшего дрон игрока.
2. Возьмите пульт и нажмите ПКМ по **своему** дрону. Пульт сохранит UUID дрона и владельца. Для выбора другого своего дрона повторите привязку.
3. Наденьте FPV-очки в слот головы. Возьмите привязанный пульт в одну из рук.
4. Нажмите ПКМ в воздух. После подтверждения сервера камера переключится на дрон.
5. Управляйте дроном, следите за сигналом и безопасностью неподвижного тела. Нажмите **R** для выхода.

Пульт без привязки или с чужим владельцем, отсутствие очков, занятый/удалённый дрон и слишком большое расстояние дают отказ с сообщением. Ванильный `/summon shahed:drone` создаёт сущность без владельца и не заменяет штатное размещение для полёта. Привязка хранится в самом предмете, поэтому переименование или совпадение имени дрона не дают доступ к чужому управлению.

| Клавиша по умолчанию | Действие в FPV |
| --- | --- |
| `W` / `S` | Вперёд / назад |
| `A` / `D` | Влево / вправо |
| `Space` / `Left Ctrl` | Подъём / снижение |
| `Left Shift` | Торможение |
| Мышь | Поворот и тангаж |
| `←` / `→` | Поворот с клавиатуры |
| `↑` / `↓` | Тангаж с клавиатуры |
| `R` | Завершить FPV-сеанс |
| `K` | Параметры FPV |

Максимальная скорость — 16 м/с. Отпущенный ввод постепенно гасит инерцию до зависания; тормоз отключает тягу и быстро снижает скорость. Вперёд/назад следуют направлению носа, а подъём/снижение действуют по вертикали мира. Тангаж ограничен ±65°, крен формируется автоматически при повороте и боковом движении. При завершении управления дрон сразу зависает; сохранение мира не восстанавливает старую скорость и команды. Столкновения ограничивают движение, обычный урон может уничтожить дрон; взрывы и игровые боевые последствия не добавлены.

Клавиши меняются в стандартных **Настройки → Управление → Назначение клавиш**, раздел SHAHED.exe FPV. FPV использует отдельные назначения; при их изменении проверьте конфликты. Меню `K` доступно и без подключения. Параметры FPV: множитель чувствительности мыши 0,10–3,00 (по умолчанию 1,00), сглаживание ориентации 0–0,50 с (0,12 с), инверсия тангажа (выключена). Учитываются стандартная чувствительность Minecraft и её настройки инверсии. Положение камеры использует обычную интерполяцию сущности; отдельная плавность относится к ориентации. Во время FPV выход доступен через `R` или кнопку выхода в этом меню; обычное использование предметов и смена панели быстрого доступа заблокированы. Параметры сохраняются локально в `config/shahed-fpv.json`. Открытое меню включает торможение дрона; сервер продолжает работать.

## Связь, тело игрока и мультиплеер

Радиус связи ограничен **96 блоками**, дистанцией отслеживания клиента/сервера и уже загруженными чанками. Дрон не загружает новые чанки принудительно. HUD показывает приближение к пределу связи; это игровой индикатор расстояния, а не расчёт препятствий и радиораспространения.

Во время FPV тело не перемещается вслед за камерой и остаётся уязвимым. Сервер останавливает его обычное движение. Повреждение тела завершает подключение; смерть и смена измерения также освобождают дрон. Не используйте FPV как способ защиты тела.

Сервер проверяет владельца, связанный UUID, очки, пульт, расстояние и текущий сеанс. Клиент отправляет ограниченные команды ввода, а не готовую позицию. У каждого игрока свой сеанс; один дрон одновременно доступен одному пилоту. Без свежего ввода сервер включает торможение через 10 тиков (0,5 с при 20 TPS) и завершает сеанс через 40 тиков (2 с). Клиент также выходит при отсутствии серверной телеметрии в течение 5 с. Камера возвращается к игроку при завершении сеанса или разрыве соединения.

Высота HUD — **координата Y мира**, не высота над ближайшей поверхностью. Время — длительность текущего подключения, не постоянный счётчик ресурса или батареи. После повторного подключения оно начинается заново.

## Оборудование и команды

| Идентификатор | Назначение |
| --- | --- |
| `shahed:drone` | Предмет для творческого размещения собственного дрона; также ID сущности |
| `shahed:controller` | Пульт с привязкой к UUID дрона и владельца |
| `shahed:fpv_goggles` | Очки для слота головы; обязательны для подключения |

```mcfunction
/gamemode creative
/shahed kit
/shahed spawn
```

`/shahed spawn` размещает дрон в 2,5 блока перед игроком. Место должно быть свободным, в загруженных чанках и границах мира. `/shahed` и предмет размещения требуют творческого режима; подключение и полёт дополнительно проверяют оборудование и владельца.

Для проверки регистрации доступны `/give @s shahed:drone`, `/give @s shahed:controller`, `/give @s shahed:fpv_goggles` и `/summon shahed:drone ~ ~1 ~` с обычными правами Minecraft. Ванильные права не меняются. Тестовую сущность можно удалить командой `/kill @e[type=shahed:drone,distance=..8]`; активный сеанс должен завершиться.
