## Границы доказательств

Minecraft, runClient/runServer, GameTests, графические тесты, симуляции мультиплеера
и бенчмарки **не запускались**. Сборка не подтверждает удобство полёта, видимость,
громкость, плавность модели, синхронизацию двух клиентов или работу сторонней защиты.
[Ручная приёмка](FLEET.md#ручная-приёмка-release-candidate) обязательна перед полноценным релизом.

Известные ограничения:

- Статический AABB не повторяет поворот крыльев/винтов; мелкие антенны декоративные.
- Без загрузки соседних чанков аппарат/модуль ждёт, не пролетает через непроверенную область.
- Перемещение quad — стабилизированное аркадное, не физическая симуляция роторов.
- Многоразовый аппарат остаётся в мире; возврат в инвентарь не реализован/не требуется для повторного полёта.
- В replay используется финальное состояние подвески; отдельный полёт выпущенного модуля не записывается.
- SAFE после гонок снимается только явным действием владельца на земле; старый тренировочный SHAHED всегда безопасен.
- Данные гонок записываются схемой 2; старый мод не должен открывать обновлённый мир.
- Universal region-protection совместимость не заявляется; сохраняются существующие callbacks/veto.
