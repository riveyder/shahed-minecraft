# SHAHED.exe 0.5.0 — Foundation

База: чистая feat/stage-three, 5eb9c20 (v0.4.2). Ветка и предыдущая работа сохранены.

## Реализация

- Винт: только два существующих кубоида лопастей, группа propeller, ось Z.
  Pivot Java (0,16.1,33.125), Blockbench (0,7.9,33.125). Положение в покое, размер,
  UV и текстура совпадают с 0.4.2; пользовательский исходный bbmodel не изменён.
  Экспортёр сохраняет новую группу. Серверная THROTTLE уже передаётся наблюдателям;
  клиент интегрирует скорость каждый игровой тик (плавность разгона 0,35 с, выбега 0,65 с),
  рендер интерполирует угол без перехода через кратчайшую дугу. При нулевой тяге
  скорость затухает до точного нуля. При низком TPS анимация следует времени мира.
- Одна существующая вкладка Creative, четыре предмета без повторной регистрации:
  «КРИВЫЕ РУКИ AEROSPACE» / «KRIVYE RUKI AEROSPACE», иконка обычного дрона.
- Обычное Survival-размещение, расход одного предмета после успешного spawn.
  Препятствие/запрет/незагруженный чанк не расходуют предмет. Creative сохраняет его.
- Краткие подсказки RU/EN. UUID владельца и дрона сохраняются; чужое управление
  по-прежнему отклоняется сервером. Красться + ПКМ вне FPV очищает только поля привязки.
  Перепривязка к своему новому дрону снимает отметку уничтожения.
- Подтверждённое уничтожение помечает связанные пульты в инвентарях/второй руке
  подключённых игроков. Недоступность/выгрузка/другое измерение не стирают UUID.
  Отключение игрока завершает управление и снимает тягу, повторный вход не запускает
  управление автоматически. Подключение возможно, когда дрон жив и загружен в том же измерении.
- Администратор в K → Мультиплеер управляет deploymentEnabled и deploymentAdminOnly;
  по умолчанию размещение разрешено всем игрокам с правом строительства.
  Проверки действуют на предметы и командный spawn, оба варианта дрона.
  Настройки сохраняются в серверный JSON, синхронизируются и сохраняются при выборе пресетов.
  Личные настройки не меняются. Протоколы settings_request_v3/settings_state_v4:
  обновите мод на сервере и клиентах одновременно.

## Рецепты

Все рецепты — vanilla shaped crafting, результат один существующий предмет.
Recipe book открывает их при получении железного слитка.

| Предмет | Материалы | Ряды верстака |
|---|---|---|
| SHAHED | 2 железа, 1 доска, 2 меди, 1 TNT, 1 редстоун | IPI / CTC / ·R· |
| Тренировочный дрон | 2 железа, 1 доска, 2 меди, 1 белая шерсть, 1 редстоун | IPI / CWC / ·R· |
| Пульт | 3 железа, 1 медь, 1 редстоун | ·R· / ICI / ·I· |
| FPV-очки | 2 стекла, 1 кожа, 2 железа, 1 редстоун | GLG / IRI |

I — железный слиток, P — любые доски, C — медный слиток, T — TNT, W — белая шерсть,
R — редстоун, G — стекло, L — кожа, · — пустая клетка.

## Ручная приёмка

1. Survival: скрафтить четыре предмета, проверить recipe book и расход/сохранение при размещении.
2. Винт: разгон, смена тяги, выбег, остановка; корпус не вращается вокруг вала.
3. Два игрока: видимость винта наблюдателю, отказ в чужой привязке/управлении.
4. Выход/повторный вход, выгрузка чанка, уничтожение, перепривязка и сброс пульта.
5. Ограничения размещения обычным игроком и администратором, перезапуск сервера,
   переключение SAFE/NORMAL/CHAOS с сохранением ограничений.
6. Регрессия FPV, взрыва/звука/дыма/огня и replay на игровом клиенте.
