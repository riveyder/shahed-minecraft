Если в локальном `options.txt` уже осталось старое назначение, переназначьте его в меню управления. Фоновые запросы ключей онлайн-аутентификации Minecraft в среде разработки завершались `Connection refused`; локальный мир, полёт и тесты работали, внешняя онлайн-аутентификация не проверена.

## Подготовка и автоматический запуск

Нужны JDK 25, Minecraft 26.2, Fabric Loader 0.19.5 и Fabric API 0.161.0+26.2. Для клиента нужна графическая среда. Используйте отдельный творческий тестовый мир с командами, без ценных данных. Для обычного сервера прочитайте и самостоятельно примите EULA.

```bash
java -version
./gradlew --version
./gradlew build
```

`build` включает GameTest. Для отдельного повторного запуска серверных тестов используйте `./gradlew runGameTest`. Проверьте свежий XML, код возврата и итог `BUILD SUCCESSFUL`; старый отчёт не подтверждает новую сборку.

Проверьте состав `build/libs/shahed-fpv-mayhem-0.2.0.jar`: `fabric.mod.json`, общий и клиентский код, mixin-конфигурации, модели, текстуры и три локализации. В бинарном моде не должно быть миров, кэшей и секретов. `-sources.jar` не устанавливают в `mods`.

## Полный сценарий первого полёта

Запустите `./gradlew runClient` или установленный профиль Fabric. Создайте чистый творческий мир, выполните `/shahed kit`.

- [ ] Предметы имеют читаемые имена, актуальные подсказки и текстуры на русском, украинском и английском языках.
- [ ] Дрон размещается предметом на свободной площадке; `/shahed spawn` также создаёт принадлежащий игроку дрон.
- [ ] ПКМ пультом по собственному дрону выводит подтверждение привязки с идентификатором.
- [ ] Наденьте очки в слот головы, держите привязанный пульт и нажмите ПКМ в воздух: камера перемещается к дрону.
- [ ] Мир занимает весь экран; нет окна в окне, руки игрока или модели дрона перед камерой, случайного третьего лица и обычного прицела.
- [ ] После принудительного переключения перспективы FPV остаётся видом от дрона, после выхода восстанавливается прежняя перспектива.
- [ ] Тело остаётся в исходном месте; второй наблюдатель видит неподвижного игрока и летящий дрон.

Проверьте движение на просторной площадке без случайного выхода за дальность:

- [ ] `W/S/A/D` плавно разгоняют дрон в ожидаемых направлениях относительно его курса.
- [ ] Отпущенные клавиши оставляют инерцию; тормоз `Left Shift` заметно сокращает движение.
- [ ] `Space` поднимает, `Left Ctrl` опускает дрон.
- [ ] Мышь и стрелки меняют направление и тангаж; горизонтальное и вертикальное управление не перепутаны.
- [ ] Крен и тангаж видны снаружи и отражаются в FPV без переворота изображения или резких скачков через ±180°.
- [ ] Дрон не проходит сквозь твёрдый блок и не выходит за границы мира/незагруженных чанков.
- [ ] После выхода из управления дрон перестаёт получать ввод и безопасно останавливается; повторное подключение работает.

## Настройки и HUD

- [ ] Все назначения находятся в стандартном меню управления и переназначаются; проверьте конфликт клавиш.
- [ ] `K` во время FPV открывает параметры; пока меню открыто, дрон не получает продолжающееся нажатие старой клавиши.
- [ ] Минимальная и максимальная чувствительность меняют скорость поворота без скачков.
- [ ] Плавность `0` и ненулевое значение дают ожидаемую разницу; мышь не вращает тело игрока.
- [ ] Инверсия тангажа действует; параметры сохраняются после перезапуска клиента.
- [ ] HUD показывает скорость в м/с, Y мира, сигнал, время текущего подключения и правильный UUID.
- [ ] При движении скорость меняется; при подъёме растёт Y; время начинает новый отсчёт при новом подключении.
- [ ] При удалении от тела сигнал уменьшается, у границы связи сеанс завершается понятным сообщением.
- [ ] При маленьком окне и разных масштабах GUI значения и подсказки не перекрываются и не обрезаются.
- [ ] F1, меню паузы, изменение размеров окна и перезагрузка ресурсов `F3+T` не оставляют сломанную камеру или зависшие клавиши.

Сигнал — индикатор расстояния; высота — абсолютная координата Y. Этот этап не заявляет батарею, высотомер над землёй или физическое радиораспространение.

## Владение, привязка и сохранение

- [ ] Пульт без привязки сообщает об этом и не подключает камеру.
- [ ] Без очков в слоте головы подключение отклоняется; одних очков без пульта недостаточно.
- [ ] Повторная привязка к другому своему дрону меняет управляемый UUID.
- [ ] Игрок B не может привязать пульт к дрону A.
- [ ] Переданный игроку B пульт A не даёт управлять дроном A.
- [ ] Дрон, созданный ванильным `/summon` без владельца, не присваивается случайным кликом.
- [ ] Удалённый или находящийся в другом измерении дрон не подключается.
- [ ] Сохраните мир, выйдите и запустите его заново: владелец дрона и UUID в пульте сохраняются, прежнее подключение не восстанавливается самопроизвольно.
- [ ] Повторите после полного перезапуска выделенного сервера.

В выживании `/shahed kit`, `/shahed spawn` и предмет размещения сохраняют ограничение творческого режима. Полёт уже выданного собственного оборудования проверяется отдельно. Обычные `/give` и `/summon` следуют ванильным серверным разрешениям.

## Безопасное завершение

Для каждого случая начните новый FPV-сеанс. После завершения камера, мышь, HUD и выбранная перспектива должны вернуться к игроку; старые клавиши не должны двигать тело или другой дрон. Повторное подключение должно работать, если оборудование и дрон сохранены.

- [ ] Нажмите `R`.
- [ ] Откройте `K` и нажмите кнопку выхода из FPV. Обычное использование пульта во время FPV блокируется вместе с игровыми действиями.
- [ ] Снимите очки или уберите пульт из обеих рук.
- [ ] Нанесите урон телу игрока; отдельно проверьте смерть и возрождение.
- [ ] Удалите управляемый дрон через `/kill` либо уничтожьте его предусмотренным игровым способом.
- [ ] Переместите тело командой телепортации; отдельно смените измерение.
- [ ] Удалитесь к пределу связи и загруженных чанков.
- [ ] Разорвите соединение, затем подключитесь заново.
- [ ] Остановите сервер во время полёта.
- [ ] При остановке поступления пакетов управления сервер завершает сеанс по тайм-ауту; последнее ускорение не сохраняется бесконечно.

## Несколько клиентов и выделенный сервер

Запустите отдельный Fabric Server для закреплённых версий и подключите **два настоящих клиента** с модом. Автоматические тесты с серверными тестовыми игроками не заменяют эту проверку.

- [ ] Сервер загружается без обращения к клиентским классам и принимает клиентов.
- [ ] A и B создают по собственному дрону, привязывают свои пульты и одновременно входят в FPV.
- [ ] Ввод A меняет только дрон A; ввод B — только дрон B. Каждый HUD показывает свой UUID.
- [ ] Наблюдатель видит синхронные позиции, курс и наклоны; корректировки сервера не вызывают длительного дрожания камеры.
- [ ] Один дрон не получает двух активных пилотов.
- [ ] Выход/смерть/отключение A освобождает его сеанс, не закрывая сеанс B.
- [ ] Уменьшите дистанцию прорисовки клиента и сервера: потеря отслеживания корректно завершает сеанс, не оставляя чёрную камеру.
- [ ] Перезапуск сервера сохраняет дроны и пульты, очищает активные сеансы.

## Модель, ресурсы и GitHub

- [ ] Проверьте нос модели при yaw 0°/90°/180°/−90° снаружи, отображение текстуры со всех сторон и направление крена/тангажа при полёте.
- [ ] `F3+T` не вызывает пропажу ресурсов или ошибки mixin.
- [ ] После фактической отправки изменений GitHub Actions использует JDK 25 и Wrapper, проходит сборку и публикует бинарный JAR + XML-отчёт как Artifacts.
- [ ] Скачанный JAR запускается в отдельном профиле; наличие workflow само по себе не является подтверждением удалённого CI.

Реплеи, гонки, режиссёрский режим, расширенные визуальные эффекты и Advanced не реализуются и не проверяются на этом этапе.
