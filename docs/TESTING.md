## Подготовка

- JDK 25, Minecraft Java Edition 26.2, Fabric Loader 0.19.5 и Fabric API 0.161.0+26.2.
- Для клиентского сценария — рабочая графическая среда.
- Чистый тестовый мир без ценных данных и без других модов, кроме необходимых Fabric-зависимостей.
- Для команд — игрок с разрешением на их использование. Для `/shahed` — творческий режим.
- Для сервера — отдельная тестовая папка, установленный Fabric Server и самостоятельно принятое соглашение EULA.

## Сборка и состав JAR

```bash
java -version
./gradlew --version
./gradlew build
jar tf build/libs/shahed-fpv-mayhem-0.1.0.jar
```

Ожидается:

- [x] `java -version` показывает JDK 25, Gradle использует совместимую Java.
- [x] `./gradlew build` завершается с кодом 0 и `BUILD SUCCESSFUL`.
- [x] Создан `build/libs/shahed-fpv-mayhem-0.1.0.jar`.
- [ ] В JAR есть `fabric.mod.json`, общие и клиентские классы, текстуры, модели предметов и локализации.
- [ ] Скомпилированные клиентские классы могут присутствовать в JAR, но общий entrypoint не загружает их на выделенном сервере.
- [ ] В устанавливаемом JAR нет миров, локальных секретов или случайно добавленных кэшей.

`-sources.jar` предназначен для разработки. Отдельно убедитесь, что Artifact CI содержит устанавливаемый бинарный JAR.

## Клиент: регистрация и команды

Запустите клиент, создайте новый творческий мир с разрешёнными командами.

- [ ] Мир открывается без ошибок регистрации сущности, предметов и ресурсов.
- [ ] Выполнение `/shahed kit` выдаёт дрон, пульт и FPV-очки.
- [ ] У предметов читаемые названия и подсказки, отсутствует значок пропавшей текстуры.
- [ ] `/shahed spawn` создаёт ровно одну сущность дрона и не даёт ошибку выполнения.
- [ ] Предмет дрона можно использовать в предусмотренном творческом сценарии размещения.
- [ ] `/give @s shahed:drone`, `/give @s shahed:controller`, `/give @s shahed:fpv_goggles` распознают идентификаторы.
- [ ] `/summon shahed:drone ~ ~1 ~` распознаёт сущность при наличии обычных ванильных прав.
- [ ] Пульт и очки ясно сообщают об ограничении этапа 1; их использование не включает фиктивный FPV-сеанс.
- [ ] Если ношение очков в слоте головы поддержано реализацией, экипировка работает; отсутствие FPV остаётся ожидаемым поведением.

Проверка отказа в неподходящем режиме:

```mcfunction
/gamemode survival
/shahed kit
/shahed spawn
```

- [ ] В режиме выживания специальные `/shahed kit` и `/shahed spawn` не выдают оборудование и не создают дрон.
- [ ] Возвращается понятное сообщение или команда недоступна согласно её требованиям.
- [ ] Переход обратно в творческий режим восстанавливает разрешённый сценарий.

Ванильные `/give` и `/summon` при наличии прав могут работать в выживании: ограничение `/shahed` не должно подменять правила Minecraft.

## Модель, текстура и ориентация

Создайте четыре дрона, каждый раз поворачиваясь в соответствующую сторону перед `/shahed spawn`: юг (yaw 0°), запад (90°), север (180°), восток (−90°/270°). Значения взгляда игрока можно сверять через экран отладки F3.

| Направление | Проверка |
| --- | --- |
| Юг, yaw 0° | Нос указывает на юг |
| Запад, yaw 90° | Нос указывает на запад |
| Север, yaw 180° | Нос указывает на север |
| Восток, yaw −90°/270° | Нос указывает на восток |

- [ ] Все четыре направления совпадают с ориентацией сущности, нос не развёрнут на 90° или 180°.
- [ ] Видны корпус и узнаваемый треугольный силуэт крыла; модель не выглядит одиночным кубом.
- [ ] Винт находится у хвостовой части, нос и хвост можно различить.
- [ ] Есть видимые элементы двигателя и фирменная маркировка.
- [ ] Серо-белая текстура отображается без стандартной коричневой окраски и без чёрно-пурпурных областей пропавших ресурсов.
- [ ] Модель проверена спереди, сзади, сбоку, сверху и снизу; нет случайно исчезающих поверхностей или неверно повёрнутых частей.
- [ ] Размер и высота модели согласованы с положением сущности; нет заметного смещения относительно места создания.
- [ ] `F3+T` перезагружает ресурсы без пропажи модели, текстуры или исключений в журнале.

Это проверка первоначальной модели. Полётная анимация и звук не входят в этап 1 и не должны отмечаться как проверенные.

- [ ] Сохраните мир и полностью выйдите из него.

- [ ] В журнале нет ошибок чтения/записи состояния сущности или отсутствующего типа.
- [ ] Повторите сценарий после остановки и запуска тестового сервера.

Эта проверка относится к существованию базовой сущности. Постоянные привязки пульта, владение и телеметрия будут проверяться после их реализации.

## Выделенный сервер

Установите бинарный JAR и Fabric API в `mods` сервера для закреплённых версий. Запустите Fabric launcher с Java 25; после первого запуска прочитайте и самостоятельно примите EULA.

```bash
java -Xms1G -Xmx2G -jar fabric-server-launch.jar nogui
```

- [ ] Сервер завершает загрузку и принимает подключения.
- [ ] Нет `NoClassDefFoundError`, `ClassNotFoundException` или ошибок загрузки клиентских renderer/model-классов на сервере.
- [ ] Клиент с тем же модом подключается, получает комплект в творческом режиме и создаёт дрон.
- [ ] Другой подключённый клиент видит базовую сущность, если такая проверка фактически выполнена.
- [ ] Перезапуск сохраняет дрон и не создаёт ошибок загрузки.
- [ ] Команды, требующие игрока, корректно обрабатывают вызов из серверной консоли, без падения сервера.

Результат с двумя клиентами записывайте только после реального запуска двух клиентов. Привязки, независимое управление, FPV и обработка разрыва полётного сеанса на этапе 1 отсутствуют; данный сценарий их не подтверждает.
