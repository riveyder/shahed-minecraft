# Графическая проверка 0.3.0 — 2026-10-17

Снимки получены настоящим Minecraft 26.2 из `ClientSmokeTest`, затем просмотрены.
Команда: `gradlew.bat runClientGameTest -PclientTests --offline` — BUILD SUCCESSFUL.
Один клиент, интегрированный тестовый сервер; NVIDIA RTX 3080, OpenGL, OpenAL.

- `0000_integrated-shahed-model.png`: модель присутствует в мире, текстура загружена.
- `0001_integrated-shahed-fpv.png`: собственный корпус/рука скрыты, английский HUD.
- `0002_integrated-shahed-night-vision.png`: применение цветного lightmap-фильтра.
- `0003_integrated-shahed-signal.png`: подтверждённое уничтожение, чёрный ящик и кнопки.
- `0004_integrated-shahed-replay.png`: визуальная копия видима от третьего лица, режим 0,25×.

Тест проверяет сетевое подключение, получение записи, запуск повтора, восстановление
камеры игрока и освобождение серверного просмотра. Полёт в этом сценарии статичен;
снимки не подтверждают динамическую интерполяцию, физику на длинном маршруте,
качество звука, тёмное окружение, все ракурсы или работу двух клиентов.
Видимый в повторе дым относится к исходному взрыву в живом мире.

Дополнительный dedicated-сценарий был запущен и заблокирован до соединения:
Minecraft потребовал принятие EULA. `eula.txt` автоматически не менялся.
После принятия пользователем соглашения в тестовом каталоге сценарий запускается
с `-PclientTests -PdedicatedClientTests`. Он всё равно не заменяет двух клиентов.
