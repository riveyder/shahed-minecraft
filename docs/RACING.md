# Гонки и испытания 1.0.0

## Участие

Скрафтите тренировочный SHAHED (белая шерсть вместо TNT) или новый FPV без подвески,
разместите, привяжите свой пульт, наденьте очки и подключитесь к FPV.
Откройте настройки (по умолчанию K) → «Гонки». Выберите трассу → «Участвовать».
Трассы меню относятся к текущему измерению. Предварительный просмотр не начинает заезд.
Меню не приостанавливает мир; начинайте на безопасной площадке.

Пересеките зелёное стартовое кольцо центром дрона. Таймер включается на старте,
затем нужно последовательно пересечь остальные кольца. Следующее — зелёное,
будущие — светлые. Последнее кольцо завершает попытку. Обратное направление
пересечения допустимо, повторное прохождение уже зачтённого кольца ничего не даёт.
Пропущенное по порядку кольцо нужно пройти заново, когда оно станет следующим.

HUD сохраняет обычную FPV-телеметрию и добавляет время, прогресс и два рекорда.
Результат отображается 10 секунд. Повторный вход на трассу начинает новую попытку;
кнопка отмены или `/shahed race cancel` завершает текущую. Просмотр колец длится 30 секунд.

Публичные команды:

| Команда | Действие |
|---|---|
| `/shahed race help` | Справка |
| `/shahed race list` | Все разрешённые трассы с измерениями |
| `/shahed race join <id>` | Подготовить попытку на тренировочном SHAHED или новом FPV без подвески |
| `/shahed race preview <id>` | Показать кольца текущего измерения без заезда |
| `/shahed race cancel` | Отменить попытку/предпросмотр |
| `/shahed race records <id>` | Личный рекорд, рекорд трассы, лучшие 10 пилотов; необязательный аргумент категории shahed/quad/contact_quad/jet |

## Редактирование администратором

Нужно право `COMMANDS_GAMEMASTER` (обычно оператор уровня 2).
Редактор использует **позицию глаз тела игрока**, не FPV-камеры; выйдите из FPV.
Кольцо вертикальное, его плоскость поперёк горизонтального направления взгляда.
Имя-идентификатор: 1–32 символа `a-z`, `0-9`, `_`, `-`.

Пример: в каждой из трёх разных позиций выполните соответствующую команду:

```text
/shahed race create valley time_trial
/shahed race gate start 4
/shahed race gate add 4
/shahed race gate finish 4
/shahed race save
/shahed race preview valley
```

Между командами колец перемещайтесь на желаемое место. Соседние центры должны
отстоять минимум на 2 блока. Для удобного взлёта и пролёта учитывайте размер модели.
Сохранение требует минимум старт и финиш. Несохранённый черновик принадлежит
редактору и исчезает при его отключении или перезапуске.

| Команда после `/shahed race` | Действие |
|---|---|
| `create <id> time_trial` | На время: радиус по умолчанию 4 |
| `create <id> precision` | Точный полёт: радиус 1,5, максимум 2,5 |
| `create <id> obstacle` | Полоса препятствий: радиус 3, местность выбирает администратор |
| `edit <id>` | Копировать сохранённую трассу в черновик |
| `gate start [radius]` | Задать/переместить старт в текущую позицию |
| `gate add [radius]` | Добавить промежуточное кольцо перед финишем |
| `gate finish [radius]` | Задать/переместить финиш |
| `gate set <index> [radius]` | Переместить кольцо в текущую позицию и задать радиус; индексы с 1 |
| `gate remove <index>` | Удалить кольцо; после удаления финиша задайте новый |
| `save` | Сохранить черновик; изменение геометрии сбрасывает рекорды и активные попытки |
| `enabled <id> true/false` | Открыть/закрыть участие; выключение отменяет попытки |
| `delete <id>` | Удалить трассу и её рекорды, отменить попытки |

Радиус 1–16 блоков (precision 1–2,5). Без явного радиуса используется стандарт типа.
Максимум 64 трассы на мир, 64 кольца на трассу, 1024 записи игрок/тип на трассу.
При заполнении рекордов существующие пилоты продолжают обновлять свои результаты;
новому пилоту явно сообщается, что его результат не сохранён.

## Сохранение, сеть и безопасность

`<мир>/shahed-races.json` содержит схему version=2 (загрузка старой version=1 поддерживается), маршруты, тип, доступность,
измерение и лучшие времена по UUID с именами. Сохранение выполняется через временный
файл и атомарную замену, где она поддерживается. Некорректный файл сохраняется
без перезаписи, загрузка трасс/запись блокируются с ошибкой в серверном логе.
Исправление такого файла требует остановки и повторного запуска сервера.

Таймер — серверное игровое время (50 мс/тик), с дробной частью пересечения кольца.
При низком TPS реальное время отличается. Клиент получает состояние каждые 5 тиков
и при прохождении кольца, не передаёт время или прогресс. Проход определяется
отрезком между предыдущей и текущей позициями, в том числе через несколько колец
за тик в правильном порядке. Нет проверки габарита модели целиком внутри кольца.

Только владелец управляемого тренировочного SHAHED или нового FPV без подвески
может участвовать. Боевой SHAHED и зритель отклоняются. Гонки включают SAFE:
нет взрывов, повреждений столкновением или сброса модуля. SAFE остаётся после
заезда/отключения и снимается явно владельцем на земле. [Подробности флота](FLEET.md). Общее ограничение размещения дронов
остаётся под контролем администратора; гонки его не обходят.

Заезд отменяется при выходе из управления, отключении, смерти пилота, смене
измерения, уничтожении/выгрузке аппарата, изменении/закрытии трассы; предел — час
игрового времени с момента присоединения. После входа в мир нужно начать новую попытку.
Попытки разных игроков разделены по UUID, сохранение рекордов работает на серверном потоке.

Кольца — клиентские частицы с полным освещением, до 512 блоков от камеры и максимум
128 одновременно. Они не создают постоянные блоки/сущности и очищаются после выхода.
Фактическая видимость зависит от рендера/дальности клиента и препятствий. Предпросмотр
не загружает чанки. Без активных заездов сервер не проверяет пересечения каждый тик.
`RaceAircraft` использует общий профиль всех четырёх типов; рекорды разделены по типу.
Меню выбирает категорию по управляемому аппарату; вне FPV используется SHAHED.

## Ручная приёмка

- Создать по трассе каждого типа; проверить плоскость колец, радиус, редактирование и сохранение.
- Пройти старт, кольца по порядку и финиш; проверить пропуск, повтор, быстрый проход.
- Проверить кольца и HUD в FULL/MINIMAL, RU/EN, разных GUI scale; справку с переназначенными клавишами.
- Сверить личный/общий рекорд, улучшить время; перезапустить сервер и проверить сохранение.
- Два пилота одновременно: независимые таймеры/прогресс, общий рекорд, отмена только своего заезда.
- Отключение/переподключение, уничтожение дрона, смена измерения и редактирование активной трассы.
- Обычный игрок: участие доступно, редактирование/удаление запрещено; боевой/чужой дрон не принимается.
- Столкновение тренировочного дрона не вызывает взрыв/разрушение; стандартный боевой дрон вне гонок не изменён.
- Регрессия: винт, четыре рецепта, Creative-вкладка, привязка, FPV, звук, дым/огонь и replay.

Minecraft и мультиплеер для 1.0.0 автоматически не запускались; этот список выполняет пользователь.
